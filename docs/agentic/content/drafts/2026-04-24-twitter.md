**Tweet 2 — Parent UX**

> 1/ Parent pages now handle errors properly.
>
> Before: if your guides or child profiles failed to load, you'd see a blank screen and have no idea what happened.
>
> Now: a clear message — "Failed to load your children. Try again." — with a retry button.
>
> Building for Africa means building for interrupted connections. Graceful errors aren't optional.

**Tweet 3 — Accessibility**

> 2/ The parent dashboard now works fully with keyboard navigation.
>
> We had a bug where the child profile cards were nested buttons — invalid HTML that breaks screen readers and keyboard users.
>
> Fixed. Full keyboard access. WCAG 2.1 compliant.
>
> A parent shouldn't need a touchscreen to use Awade. Neither should a teacher.

**Tweet 4 — Honest UX**

> 3/ We removed a lie from the Settings page.

>
> Now it says: "Email and password updates aren't available yet. Contact support."
>
> Honest UX > fake confirmations. Always.
